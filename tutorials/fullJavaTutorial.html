Coding In Java

Java is a multiplatform, object-oriented programming language that runs on billions of devices worldwide. It powers applications, smartphone operating systems, enterprise software, and many well-known programs. Despite having been invented over 20 years ago, Java is currently the most popular programming language for app developers.

To start coding in Java, all you need to do is to make a file. We will make a file named Hello.java. In that file, we will create a class. In Java, your class must be the name of your file; otherwise, it won't work. You must also provide a main function. Inside of that function, we will create a new int variable and print it to the console.

Hello.java
public class Hello { }

public static void main(String... args) {
 int thisIsAnInt = 10;
 System.out.println(thisIsAnInt);
}

"int" variables and "double" variables are very different from each other. Even though they both deal with numbers, doubles carry a higher level of precision than ints. Ints can only deal with whole numbers, while doubles can deal with decimals too.

Enums are another data type. Enum is a data type that assigns names to a set of named constants, making code more readable and maintainable by using descriptive names instead of raw values. An example of an enum is below:

enum daysOfTheWeek {
 Sunday,
 Monday,
 Tuesday,
 Wednesday,
 Thursday,
 Friday,
 Saturday
}

Time for some if functions! There are many different ways of comparing two variables. For example, are two variables equal, not equal, less than, greater than? Do the variables even exist? Some examples are below:

if (10 == 5) { } // Equal To
if (10 != 5) { } // Not Equal To
if (10 > 5) { } // Greater Than
if (10 >= 5) { } // Greater Than Or Equal To
if (10 < 5) { } // Less Than
if (10 <= 5) { } // Less Than Or Equal To

As you might have noticed, we use 2 equal signs for some comparisons and 1 for others. Normally, this is what the equal signs mean:

  • 1 equal sign (=) is the assignment operator. It's used to assign a value to a variable.
  • 2 equal signs (==) is the equality operator. It is used to compare two values to check if they are equal.

But why only 1 equal sign for greater/less than or equal to (>=)? This is because combined operators like >= are shortened to 2 characters. If it were written as >==, it would be confusing. This is the same for not equal to.

A shorted way to write "not equal to" or "equal to" while commenting or documenting would be to use NEQ and EQU respectively. This will save time while commenting during coding.

Now, let's try to run that code that we wrote earlier (Hello.java). Unlike other programming languages, Java must be compiled before it is run. When you write Java code, you write it in human-readable form. However, the computer doesn't understand Java directly. Java is a high-level programming language, and to execute your program, it must be translated into machine code, which is specific to the hardware and operating system. To compile it, we will use the "javac Hello.java" command. Once we have run that command, we can run the "java Hello" command to finally run the program.

Here's where things get interesting. Java is also an inheritance based language. This means that you can have multiple classes build off of a different single class. For example, you can have a class based on making an animal. You can then use that same class in another class to make a dog. Here's a code example:

public class Animal {
 public void makeSound() {
  System.out.println("Some sound");
 }
}

public class Dog extends Animal { // Notice the "extends" keyword here.
 @Override
 public void makeSound() {
  System.out.println("Bark");
 }
}

Now, arrays and maps. Imagine arrays like a shopping list. There are many items that you can access. Maps are like arrays, but different in the fact that there is a value assigned to each item. Now, each item on that shopping list has a specific brand assigned to it. Here's a code example:

// Array
List<String> list = new ArrayList<>();
 list.add("Apple");
 list.add("Banana");
list.get(0); // Returns "Apple" because it is in the 0th index.

// Map
Map<String, Integer> ageMap = new HashMap<>();
 ageMap.put("Alice", 25);
 ageMap.put("Bob", 30);
 ageMap.put("Charlie", 35);
ageMap.get("Alice"); // Returns the integer "25".

Instead of doing if-else statements over and over for the same condition, we can use a switch. An example is below:

switch (animal) {
 case Dog:
  return "Woof";
