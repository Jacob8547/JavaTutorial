How do we install programs?

Below are the installation guides for each program you might need. You can click the links below to go to the program you need to install.

  • WPILib
  • Driver Station
  • AdvantageScope
  • REV Hardware Client
  • PathPlanner
  • Elastic
  • Raspberry Pi Imager
  • Phoenix Tuner X





WPILib

  1. Download WPILib from their website.
  2. Extract the .iso file using 7-Zip. Right Click the .iso file, select "Show More Options", 7-Zip -> Extract Files.
  3. Run the WPILib installer "WPILibInstaller.exe".
  4. Select the "Everything" option when prompted to select the install mode.
  5. Select "Download for this computer only (fastest)" when prompted to select the VS Code installation.
  6. Restart your computer when the installer has finished.





Driver Station

  1. Go to the FRC Game Tools website.
  2. Login using a National Instruments account.
  3. Press the download button.
  4. Run the installation executable.
  5. Continune through the screens until installation.
  6. Restart your computer when the installer has finished.





AdvantageScope

  1. Go to the AdvantageScope download page and download the latest release for your operating system.
  2. Run the installation executable.





REV Hardware Client

  1. Go to the REV Hardware Client installation page.
  2. Run the installation executable.
  3. Continune through the screens until installation.





PathPlanner

  1. Go to the PathPlanner download page and download the latest release for your operating system.
  2. Continune through the screens until installation.





Elastic

  1. Go to the Elastic download page and download the latest release for your operating system.
  2. Continune through the screens until installation.





Raspberry Pi Imager

  1. Download the most recent installer for your operating system at Raspberry Pi's website.
  2. Run the installer.





Phoenix Tuner X

  1. Open the "Microsoft Store" application or the equivalent on other operating systems.
  2. Search for "Phoenix Tuner X"
  3. Install the application.
